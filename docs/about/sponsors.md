# Sponsors

<span class="kz-eyebrow">KARTOZA · SUSTAINABILITY</span>

timvim is free and open source, and it is maintained in the open by
[Kartoza](https://kartoza.com). Keeping it healthy — tracking upstream Neovim and
NVF, updating language tooling, fixing bugs and writing documentation — takes
ongoing time. If timvim saves you setup effort and makes your day nicer, please
consider helping to keep it sustainable.

## Ways to support the project

<div class="grid cards" markdown>

-   :material-heart:{ .lg .middle } **Become a sponsor**

    ---

    Recurring support through GitHub Sponsors is the most direct way to fund
    continued maintenance and new features.

    [:material-arrow-right: github.com/sponsors/timlinux](https://github.com/sponsors/timlinux)

-   :material-github:{ .lg .middle } **Contribute**

    ---

    Issues, pull requests and documentation improvements are all welcome. See the
    [Developer Guide](../developer-guide/index.md) to get set up.

    [:material-arrow-right: github.com/timlinux/nix-vim](https://github.com/timlinux/nix-vim)

-   :material-bullhorn-outline:{ .lg .middle } **Spread the word**

    ---

    Star the repository and tell other Nix and Neovim users. Reach helps the
    project as much as funding does.

-   :material-domain:{ .lg .middle } **Work with Kartoza**

    ---

    Kartoza builds and supports open geospatial and developer tooling. Engaging
    us on a project sustains the open-source work too.

    [:material-arrow-right: kartoza.com](https://kartoza.com)

</div>

!!! info "Where support goes"
    Sponsorship funds maintenance, compatibility updates, documentation and new
