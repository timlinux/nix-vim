# Getting Started

Welcome to **timvim** — a fully declarative, Nix-built Neovim configuration
powered by the [NVF](https://github.com/notashelf/nvf) framework. This section
walks you from a bare machine to a running editor, and explains what you will
see the first time it opens.

Everything is reproducible: the same flake produces the same editor on Linux,
macOS and WSL2, with language servers, formatters, AI assistance and a
Kartoza-branded interface already wired together.

!!! tip "New to Nix?"
    You only need Nix with flakes enabled. There is nothing to compile by hand
    and no plugin manager to babysit — the flake does it all.
